# Python Packages, Profiling and Testing

Упражнения по виртуальным окружениям, установке зависимостей, терминальным диаграммам, извлечению финансовой таблицы из HTML и профилированию. В ex05 добавлены тесты финансового парсера.

Учебный проект Школы 21. **Стек:** Python 3, requests, BeautifulSoup, PyTest, termgraph, cProfile.

## Задача и реализация

Решения расположены в `src/ex*/`: каждый каталог — отдельное упражнение. Проект показывает практику работы с указанными инструментами в рамках учебных ограничений.

## Запуск

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install requests beautifulsoup4 pytest termgraph httpx
python -m pytest src/ex05/financial_test.py -q
python src/ex03/financial.py MSFT 'Total Revenue'
```
Для ex02 требуется отдельное окружение `src/ex02/kleinega`: его путь проверяется в `librarian.py`. Окружения создаются заново на компьютере пользователя.

## Ограничения и статус

Тесты ex05 используют фиксированный HTML и подменяют HTTP-запросы и sleep. 15 проверок покрывают значения, тип результата, неверный тикер, аргументы, отсутствующие поля и ошибки сети. Они проверяют логику на тестовой разметке; совместимость с текущей вёрсткой Yahoo Finance отдельно не подтверждена. В ex03 предусмотрена задержка 5 секунд. В исходном ex04 отсутствует `pstats-cumulative.txt`. В ex02 есть опечатка `requirments.txt`, а итоговый freeze сохраняется в `requirements.txt`.
