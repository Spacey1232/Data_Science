# Python Performance Practices

Учебные эксперименты со скоростью и памятью: циклы, list comprehension, map/filter, reduce, Counter и построчное чтение через генератор.

Учебный проект Школы 21. **Стек:** Python 3, timeit, collections.Counter, functools.reduce, resource.

## Задача и реализация

Решения расположены в `src/ex*/`: каждый каталог — отдельное упражнение. Проект показывает практику работы с указанными инструментами в рамках учебных ограничений.

## Запуск

```sh
python3 src/ex02/benchmark.py loop 1000
python3 src/ex02/benchmark.py list_comprehension 1000
python3 src/ex03/benchmark.py reduce 1000 100
python3 src/ex04/benchmark.py
python3 src/ex05/generator.py path/to/input.txt
```
`resource` рассчитан на Unix-подобные системы. В ex00/ex01 задано 90 миллионов повторений: запуск может занять длительное время.

## Ограничения и статус

В текущих замерах map/filter создают ленивые итераторы без потребления, поэтому их время нельзя напрямую сравнивать со списком, который уже вычислен. `ru_maxrss` имеет разные единицы на Linux и macOS; формула в коде соответствует байтам macOS. Эти ограничения нужно учитывать при интерпретации результатов.
