# UNIX Command Line Tools

Обработка данных о вакансиях с помощью командной строки: преобразование JSON в CSV, сортировка, выделение уровней Junior/Middle/Senior, подсчёт частот и разбиение по датам.

Учебный проект Школы 21. **Стек:** Shell, jq, sort, sed, awk, cut, uniq.

## Задача и реализация

Решения расположены в `src/ex*/`: каждый каталог — отдельное упражнение. Проект показывает практику работы с указанными инструментами в рамках учебных ограничений.

## Запуск

```sh
cd src/ex01
sh json_to_csv.sh
cd ../ex02
sh sorter.sh
```
Скрипты используют относительные пути: запускай их из соответствующих каталогов упражнений. Для преобразования нужен установленный `jq`. Исходный JSON находится в `src/ex00/hh.json`.

## Ограничения и статус

В `cleaner.sh` и `counter.sh` используется `hh_position.csv`, а `partitioner.sh` ожидает `hh_positions.csv`. Перед сквозным запуском нужно согласовать имена. `concatenator.sh` удаляет переданные ему входные файлы после объединения: работай с копиями данных. В ex00 сохранён JSON; отдельного скрипта загрузки в репозитории нет.
