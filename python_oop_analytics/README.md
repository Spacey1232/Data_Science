# Python OOP: Coin Toss Analytics

Поэтапное построение анализа результатов подбрасывания монеты: чтение и проверка CSV, подсчёт частот, вложенные классы, наследование, генерация случайных результатов и текстовый отчёт.

Учебный проект Школы 21. **Стек:** Python 3, ООП, файловый ввод-вывод, logging.

## Задача и реализация

Решения расположены в `src/ex*/`: каждый каталог — отдельное упражнение. Проект показывает практику работы с указанными инструментами в рамках учебных ограничений.

## Запуск

Пример для ex05:
```sh
cd src/ex05
printf 'heads,tails\n1,0\n0,1\n1,0\n' > data.csv
python3 make_report.py
cat report.txt
```
Путь к данным и число генерируемых наблюдений задаются в `config.py`. Каждый каталог `ex00`–`ex06` представляет отдельный этап упражнения.

## Ограничения и статус

Случайные результаты — учебная симуляция, а не статистическая модель прогнозирования. Для ex06 проверь настройки внешних уведомлений перед запуском.

## Происхождение

Код взят из ветки `develop` учебного репозитория. Эта копия подготовлена для портфолио: виртуальные окружения и кэши исключены. Полные школьные методички в копию не включены.
