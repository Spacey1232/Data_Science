# MovieLens Analytics

Учебный проект анализа MovieLens на Python: рейтинги фильмов, жанры, годы выпуска и пользовательские теги. Аналитика разделена на классы `Ratings`, `Movies`, `Tags` и `Links`, использующие общий загрузчик CSV.

## Возможности

- Средние рейтинги и топы фильмов, статистика по годам.
- Распределение фильмов по жанрам и годам выпуска.
- Поиск фильмов по названию, анализ длины и частот слов в тегах.
- Сопоставление идентификаторов MovieLens и IMDb; получение внешней информации о фильмах.
- Jupyter Notebook, тесты PyTest и модуль Telegram-уведомлений.

## Установка и запуск

Python 3.10+; зависимости перечислены в `requirements.txt`.

```sh
python3 -m venv venv
source venv/bin/activate
python -m pip install -r requirements.txt
PYTHONPATH=src python -c 'from analysis.ratings import Ratings; print(Ratings().get_top_N_movies(5))'
PYTHONPATH=src python -m pytest src/analysis/tests.py -v
```

CSV-файлы ожидаются в `src/data/`: `ratings.csv`, `movies.csv`, `tags.csv`, `links.csv`. Описание данных и условия использования находятся в `src/data/README.txt`.

Альтернативная установка через `bash install.sh` также регистрирует Jupyter-ядро и перезаписывает `requirements.txt` установленными версиями. После установки Notebook запускается командой `bash run_jupyter_server.sh`.

## Структура

- `src/analysis/` — загрузка данных, аналитические классы, тесты, внешние интеграции.
- `src/config.py` — пути, лимит строк и настройки окружения.
- `src/data/` — исходные данные MovieLens.
- `librarian.py` — установка зависимостей и регистрация ядра.

## Ограничения

По умолчанию загрузчик читает до 1000 строк каждого CSV (`LIMIT` в `src/config.py`), поэтому результаты описывают выборку. Внешняя информация о фильмах зависит от сети и разметки сайта. Telegram использует переменные `TELEGRAM_TOKEN` и `TELEGRAM_CHAT_ID`; секреты не следует добавлять в Git.

README подготовлен по текущему коду. Полный набор зависимостей и тестов в этой сессии не запускался.
