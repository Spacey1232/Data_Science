# Data Science — учебные проекты

Портфолио учебных проектов Школы 21: Python, обработка данных в UNIX, объектно-ориентированное программирование, тестирование и анализ MovieLens.

## Проекты

| Проект | Содержание |
|---|---|
| [UNIX Command Line Tools](unix_command_line_tools/) | Преобразование JSON и CSV, сортировка и обработка вакансий средствами Shell |
| [Python Syntax and Semantics](python_syntax_semantics/) | Типы данных, коллекции, файлы, аргументы командной строки |
| [Python OOP Analytics](python_oop_analytics/) | Классы, наследование, обработка CSV и формирование отчёта |
| [Python Packages and Testing](python_packages_testing/) | Виртуальные окружения, HTML, профилирование и PyTest |
| [Python Performance Practices](python_performance_practices/) | timeit, Counter, генераторы, сравнение времени и памяти |
| [MovieLens Analytics](MovieLens_Analytics/) | Анализ рейтингов фильмов, жанров и пользовательских тегов |
| [Pandas Exercises](DSB7_Pandas_ID_1577650-1/) | Загрузка, очистка, агрегация, обогащение и оптимизация данных в Pandas |

В каждой папке есть отдельный README с описанием, инструкцией запуска и известными ограничениями. Команды выполняются из папки соответствующего проекта.

## Мой вклад в MovieLens

MovieLens — командная работа двух человек. Я написал исходную реализацию всех методов проекта. Затем мы с напарником совместно исправляли и дорабатывали код для соответствия техническому заданию.

## Статус

Это учебные реализации. Ограничения отдельных упражнений описаны в README проектов. В проект управления пакетами добавлено упражнение ex05 с помощью Codex: 15 изолированных от сети тестовых случаев PyTest прошли проверку. Полная проверка всех проектов не проводилась.
