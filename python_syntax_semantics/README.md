# Python Syntax and Semantics

Десять учебных упражнений по основам Python: типы данных, работа с CSV/TSV, словари, множества, аргументы командной строки и шифр Цезаря.

Учебный проект Школы 21. **Стек:** Python 3, стандартная библиотека.

## Задача и реализация

Решения расположены в `src/ex*/`: каждый каталог — отдельное упражнение. Проект показывает практику работы с указанными инструментами в рамках учебных ограничений.

## Запуск

```sh
python3 src/ex00/data_types.py
python3 src/ex02/stock_prices.py Apple
python3 src/ex05/all_stocks.py 'Apple, MSFT, unknown'
python3 src/ex09/ceasar.py encode 'Hello, world!' 3
```
Для файловых упражнений нужны входные данные: `ds.csv` в ex01, список email формата `name.surname@example.com` в ex08. Запускай такие скрипты из каталога упражнения. Цены акций заданы учебными константами.

## Ограничения и статус

Шифр Цезаря поддерживает латинские буквы и не предназначен для защиты данных. Полного набора автоматических тестов в проекте нет.
